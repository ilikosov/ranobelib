# ranobelib — парсер книг с ranobelib.me на Go

Функциональный аналог [ryadik/ranobelib-parser](https://github.com/ryadik/ranobelib-parser),
переписанный на Go. Скачивает книги (ранобэ) с сайта [ranobelib.me](https://ranobelib.me)
и сохраняет их в формате **EPUB**.

В отличие от оригинала на TypeScript, программа **не требует ни Node.js, ни
Google Chrome**: вместо управления браузером она работает напрямую с публичным
API сайта (`api.cdnlibs.org`), поэтому качает быстрее и стабильнее.

## Возможности

- 📗 Метаданные книги: название, автор, описание, обложка.
- 📚 Выбор, что качать: все тома, конкретные тома (`1,3,5`), диапазон (`1-3`)
  или первые N глав (тестовый режим).
- 📖 Режимы сохранения: один EPUB на всю книгу или каждый том отдельным файлом
  (надёжнее — при ошибке теряется только текущий том).
- 🖼️ Изображения: встраиваются в книгу; недоступные заменяются плейсхолдером.
  Есть режимы «только обложка» (без изображений глав) и «без изображений»,
  а при сетевых ошибках сборки выполняется автоматический fallback на версию
  без изображений.
- 💾 Автосохранение прогресса каждые 5 глав в `progress/`. Прерванную загрузку
  можно продолжить с того же места — программа сама предложит это при запуске.
- ⏳ Обработка ограничения запросов (HTTP 429): паузы 30/60/120 секунд с
  повторами, случайные задержки 3–7.5 с между главами, повторная догрузка
  отложенных глав.

## Установка и запуск

Требуется [Go](https://go.dev/dl/) 1.24 или новее.

```bash
git clone https://github.com/ilikosov/ranobelib.git
cd ranobelib
go build -o ranobelib .
./ranobelib
```

Программа задаст вопросы: URL книги, какие тома качать, режим сохранения,
нужны ли изображения. Готовые книги появятся в папке `books/`.

Пример URL книги: `https://ranobelib.me/ru/book/165329--kusuriya-no-hitorigoto-ln-novel`

### Неинтерактивный режим

Все параметры можно передать флагами — тогда меню не показывается:

```bash
./ranobelib -url "https://ranobelib.me/ru/book/165329--kusuriya-no-hitorigoto-ln-novel" \
  -volumes 1-3 -no-images -split
```

| Флаг         | Описание                                                |
|--------------|---------------------------------------------------------|
| `-url`       | URL книги на ranobelib.me                               |
| `-volumes`   | тома: `1,3` или `1-3` (по умолчанию все)                |
| `-first N`   | скачать только первые N глав (тестовый режим)           |
| `-no-images` | собирать EPUB без изображений                           |
| `-cover-only`| скачивать только обложку, без изображений глав          |
| `-split`     | сохранять каждый том отдельным EPUB-файлом              |

## Как это устроено

```
main.go               — сценарий: диалог → загрузка → сборка EPUB
internal/api          — клиент API (метаданные, список глав, контент глав),
                        повторы и обработка 429
internal/content      — конвертация контента глав (HTML или doc-JSON) в HTML
internal/book         — фильтрация/группировка глав, загрузчик с прогрессом
internal/progress     — сохранение и восстановление прогресса (progress/*.json)
internal/epub         — сборка EPUB (go-shiori/go-epub), встраивание изображений
internal/cli          — интерактивные меню на русском
```

## Тесты

```bash
go test ./...
```

Сетевые взаимодействия покрыты тестами на `httptest`-серверах, поэтому тесты
не требуют доступа к ranobelib.me.

## Отказ от ответственности

Программа предназначена для личного офлайн-чтения. Уважайте авторов и
переводчиков: не распространяйте скачанные книги.
